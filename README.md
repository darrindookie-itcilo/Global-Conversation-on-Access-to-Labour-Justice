ITCILO learning dashboard for Turin, 23–27 November 2026.

- [Open the dashboard](https://global-conversation-labour-justice.darrin-dookie.chatgpt.site/)

This repository currently contains the entry page only; the complete source and course-asset mirror has not yet been published here.
